# Zetta Post Bot

Telegram bot that generates and publishes expert posts about iiko restaurant automation to @zetta_uzbekistan.

## Required Environment Variables (set in Railway)

| Variable | Description |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Bot token from @BotFather |
| `ANTHROPIC_API_KEY` | Claude API key |
| `YOUR_PERSONAL_ID` | Your Telegram user ID (for approval) |
| `PEXELS_API_KEY` | Pexels API key for photos |

## Schedule
Posts at **09:00, 13:00, 19:00** Tashkent time (Asia/Tashkent).
